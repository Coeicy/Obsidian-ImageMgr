### 图床配置

支持7种图床，每种图床有独立的启用开关：

- **SM.MS**: API Token
- **Imgur**: Client ID
- **GitHub**: Token + 仓库配置
- **七牛云**: AccessKey + SecretKey + Bucket
- **阿里云**: AccessKeyId + AccessKeySecret + Bucket
- **腾讯云**: SecretId + SecretKey + Bucket
- **又拍云**: 操作员账号 + 密码

## 📱 移动端适配

| 设置项 | 说明 |
|--------|------|
| **移动端每行图片数量** | 移动端每行显示的图片数量（1-5） |
| **启用紧凑工具栏** | 移动端工具栏更加紧凑 |

| **平板端每行图片数量** | 平板设备上的每行图片数量（默认3） |
| **手机横屏每行图片数量** | 手机横屏模式（默认2） |
| **手机竖屏每行图片数量** | 手机竖屏模式（默认1） |
| **Android 相册隐藏** | 创建 `.nomedia` 文件防止扫描 |
